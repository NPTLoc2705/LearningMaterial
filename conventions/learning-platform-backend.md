# Backend Architecture & Conventions (`server/LearningPlatform/`)

> **Scope**: Primary backend solution (`server/LearningPlatform/`) for the Junior English Learning Platform, targeting **.NET 9**.  
> **Authoritative Reference**: [docs/platform/02-architecture.md](../docs/platform/02-architecture.md) and [docs/platform/03-data-model.md](../docs/platform/03-data-model.md).  
> **Dependency Rule**: Read top-to-bottom. Each layer only references the layer immediately below it (plus `BusinessObject` for shared DTOs/entities).

```
LearningPlatform.Api  ->  Service  ->  Repository  ->  DAL  ->  BusinessObject
```

---

## 1. Layer-by-Layer Rules

### Layer 1 — `BusinessObject/`
- **Contains**: EF Core entity classes, enums, and DTOs (`BusinessObject/Dtos/{FeatureGroup}/`).
- **Feature groups**: `Identity/`, `ClassManagement/`, `ContentManagement/`, `LearningActivities/`, `LearningProgress/`, `Reporting/`, `Storage/`, `Extraction/`.
- **Strict Rule**: No business logic, no EF queries. Pure data shapes only.

### Layer 2 — `DAL/` (Data Access Layer)
- **Contains**: `LearningPlatformDbContext.cs` (single DbContext using PostgreSQL schema `app`), `{Entity}DAO.cs` classes, and `DAL/Migrations/`.
- **Naming**: `{Entity}DAO.cs` (e.g., `UserDAO.cs`, `LessonDAO.cs`).
- **Migrations**: Auto-generated by EF Core (`DAL/Migrations/`). Never hand-edit migration files; only append raw SQL for RLS/schema privileges via `migrationBuilder.Sql(...)` where specified by tasks.
- **Strict Rule**: DAO classes take `LearningPlatformDbContext` directly. No HTTP types, no business rules.

### Layer 3 — `Repository/`
- **Contains**: Interfaces (`I{Feature}Repository.cs`) and implementations (`{Feature}Repository.cs`).
- **Naming suffix**: `Repository` / `IRepository` (never `Repo`).
- **Strict Rule**: Repositories call DAOs and map results. No business rules, no direct `LearningPlatformDbContext` injection.

### Layer 4 — `Service/`
- **Contains**: Interfaces (`I{Feature}Service.cs`) and implementations (`{Feature}Service.cs`).
- **Responsibilities**: All business logic — grading, question generation, `ContentValidator`, `IClassroomAccessService`, AI extraction orchestration, storage signed URLs.
- **Strict Rule**: Services inject `I{Feature}Repository` (and other service abstractions like `IClassroomAccessService`, `IFileStorage`) only. Never inject `LearningPlatformDbContext`, DAOs, or `HttpContext`.

### Layer 5 — `LearningPlatform.Api/` (API Project)
- **Contains**: ASP.NET Core controllers, middleware, `Program.cs`, configuration setup.
- **Strict Rule**: Controllers inject `I{Feature}Service` only. Never expose EF entities — return DTOs only. Use RFC 7807 `ProblemDetails` for errors.

## 2. Where New Files Go — Cheat Sheet

| What you're adding | Where it goes | Example |
|---|---|---|
| Entity / Enum | `server/LearningPlatform/BusinessObject/{FeatureGroup}/{Entity}.cs` | `BusinessObject/ContentManagement/Lesson.cs` |
| DTO | `server/LearningPlatform/BusinessObject/Dtos/{FeatureGroup}/{Dto}.cs` | `BusinessObject/Dtos/ContentManagement/LessonDto.cs` |
| DAO | `server/LearningPlatform/DAL/{FeatureGroup}/{Entity}DAO.cs` | `DAL/ContentManagement/LessonDAO.cs` |
| Repository Interface | `server/LearningPlatform/Repository/{FeatureGroup}/I{Entity}Repository.cs` | `Repository/ContentManagement/ILessonRepository.cs` |
| Repository Impl | `server/LearningPlatform/Repository/{FeatureGroup}/{Entity}Repository.cs` | `Repository/ContentManagement/LessonRepository.cs` |
| Service Interface | `server/LearningPlatform/Service/{FeatureGroup}/I{Feature}Service.cs` | `Service/ContentManagement/ILessonService.cs` |
| Service Impl | `server/LearningPlatform/Service/{FeatureGroup}/{Feature}Service.cs` | `Service/ContentManagement/LessonService.cs` |
| Controller | `server/LearningPlatform/LearningPlatform.Api/Controllers/{Feature}Controller.cs` | `LearningPlatform.Api/Controllers/LessonsController.cs` |
| Unit Tests | `server/LearningPlatform/Tests/Service.Tests/` | `Tests/Service.Tests/GradingTests.cs` |
| Integration Tests | `server/LearningPlatform/Tests/Api.IntegrationTests/` | `Tests/Api.IntegrationTests/AuthTests.cs` |
